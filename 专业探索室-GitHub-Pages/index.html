资料与推荐方法

让每一个判断，都能继续追问。

本页为讨论辅助工具，采用人工编写的标签规则：每命中一个兴趣标签计3分、优势标签计2分、任务偏好计2分；完整选科每命中一个学习基础标签再加1分（无兴趣等选择时每项计2分，用于初步探索）；可调整兴趣与优势的相对权重。仅显示有匹配线索的方向，按分数排序，不把规则分数解释为适合概率或心理测评结论。并列时沿用资料库顺序，最多展示六项。

学校、城市和资源只影响调查策略，不按家庭背景或性格标签限制专业。高中选科关联是编辑归纳的学习基础标签，默认仅保留有学习基础关联的推荐；可切换跨学科探索。完整资料库不受选科限制。关联标签不是官方报考要求。页面设置高中选科、地区和预计高考年份，但尚未核验2028年江苏逐校实际招生计划，也未采集分数、体检等条件，因此结果不是可报考名单，薪酬仅展示有来源的招聘样本，不作个人就业收入预测。未入选的专业不代表不适合。

资料库收录95个专业：用户提供的清华2025级培养方案附录93项，加上原站农学与未来机器人两项补充方向；按17个学习板块整理。它不是全国完整本科专业目录，也不是清华当前招生名单。附录星号、井号状态已保留，分别表示当时无在校生和仅辅修。课程、任务和研究方向为概览性编辑归纳，任务为示意，不冒充真实学校作业；各校安排不同。正式调查请使用目标学校、目标年级培养方案。下列历史培养方案只作为阅读样本，不视为当前招生承诺。资料检索：2026-11-21。

职业与薪酬资料

职业路径与发展方向结合课程、招聘任务归纳，不作增长率或就业保证。样本是2026年检索到的公告，包含2026届历史招聘与2027届新公告，不表示目前仍可申请。每个数字保留原月薪／年薪、地区、岗位、学历口径；本硕合并报价明确注明。没有可靠可比金额时显示“未公开可比金额”。跨专业引用同一公告不构成独立样本，不能由这些样本计算学历溢价或专业排名。
